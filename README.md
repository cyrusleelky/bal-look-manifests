# Balenciaga runway look manifests

One `manifest.json` per collection (`<slug>/manifest.json`): look number → public
image URL on balenciaga.com's own CDNs (Kering DAM or Livestory).

Published automatically by the lookbook scraper's GitHub Actions workflow and read
by the Excel / PowerPoint look-photo macro, so the macro can fetch photos without
a local folder. Data only — no images are stored here.
